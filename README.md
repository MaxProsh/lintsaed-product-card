# Карточка товара Lintsaed — CORMAK KP202

Адаптивный HTML-шаблон карточки оборудования на основе реального крестового стола CORMAK KP202. Дата проверки исходных данных: 23.10.2026.

## Просмотр

Открыть `index.html` напрямую или запустить `python -m http.server 8765` и перейти на http://127.0.0.1:8765.

Публичный просмотр после включения GitHub Pages: https://maxprosh.github.io/lintsaed-product-card/

## Что сделано

- Ключевые параметры и цена рядом с фотографией; полная таблица характеристик открыта.
- Пять оригинальных фотографий, переключение и увеличение, отдельный габаритный чертёж с таблицей A–K.
- Липкая навигация по разделам; на мобильных — фиксированная кнопка запроса поставки.
- Форма составляет письмо продавцу с моделью, городом, количеством и вопросом. Ничего не отправляет автоматически, не хранит данные. Почтовая программа открывается только отдельным действием посетителя. Есть копирование текста.
- Семантическая таблица, подписи полей, Escape для окон, видимый фокус, поддержка reduced motion, версия для печати.
- Без сборки, внешних библиотек, аналитики, сторонних сетевых запросов при открытии.

## Файлы и адаптация

`index.html` — структура и контент; `style.css` — оформление; `app.js` — галерея и запрос; `assets/` — фото, логотип, шрифты; `product.json` — проверенные данные этой модели для разработчика. JSON — справочник, страница не генерируется из него автоматически. При замене товара обновляйте HTML и JSON согласованно, а также название, адрес исходной карточки и тему/текст письма в JS.

Для полноценного станка набор основных параметров нужно заменить под категорию: например, диапазон реза, питание, мощность, скорость полотна. Параметры KP202 нельзя переносить на другие товары.

## Ограничения и факты

Это концепция интерфейса, не официальный интернет-магазин и не подключённая система заказов. Цена 229 € без НСО перенесена с исходной страницы; актуальность, ставка налога, склад, срок, доставка, оплата, комплект и гарантия требуют подтверждения продавца. Метаданные noindex запрещают индексацию, но не являются защитой доступа.

Обнаружено различие: описание содержит «верниер 2,5 мм / 0,02 мм», таблица — шаг ходового винта 2 мм. Значения сохранены с явным примечанием; техническое толкование не выдумано. Размеры 225 × 175 мм сверены с названием и чертежом A × B.

Фотографии и логотип принадлежат соответствующим правообладателям; используются по заданию для демонстрации. Права на эти материалы не передаются. Код не содержит личных данных, паролей и ключей. Шрифты сайта Montserrat и Poppins сохранены локально, лицензии приведены в `assets/`.

## Проверки

Локальный Chrome / Playwright: 1440, 1024, 768, 680, 390 и 320 px; фотографии и загрузка шрифтов; галерея; увеличение фото/чертежа; Escape; обязательный город и количество ≥1; содержание письма; копирование текста; якоря; переход к содержимому клавиатурой; масштаб 200%; reduced motion; печать. Ошибок JavaScript и загрузки ресурсов не обнаружено. Результаты — `docs/qa-results.json`.

Не проверялись: screen reader, Safari/Firefox, реальная отправка письма и ответ продавца. Рост конверсии не измерен. Гипотеза: доступные параметры и понятный запрос уменьшат число действий до обращения; проверять по доле квалифицированных запросов и их стоимости после внедрения аналитики.
